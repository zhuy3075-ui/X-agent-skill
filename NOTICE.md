# Attribution and scope

X-agent-skill is an independent MCP service and skill bundle. It is not an official X/Twitter product.

The `Scweet/` directory contains the runtime required by this service, based on
[Altimis/Scweet](https://github.com/Altimis/Scweet), version 5.8.1, with local configuration and
account-check changes. Its original MIT copyright notice is preserved in [LICENSE](LICENSE).
The desktop GUI is not part of this distribution. Runtime credentials and collected data are not included.

The MCP API, independent collector and skills are distributed under the same MIT license.
The bundled runtime avoids relying on unmodified Scweet distributions that lack the service's settings.
