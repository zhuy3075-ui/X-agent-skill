## 用户可自行运行的检查

使用安装后的虚拟环境，填写自己的数据库配置并初始化后运行：

```bash
python scripts/check_service.py --config config.json
```

正常结果包含 `healthy=true`、`tools=31`、`database_read=true`。
该检查不创建采集或监测任务，也不需要 X token。

## 尚未验证的范围

- 正式服务器、Linux/macOS 实机安装、systemd／nginx 模板和外网 HTTPS 部署。
- 本次发布没有重新执行真实 X 采集、真实多账号吞吐或删帖端到端实验。
- 共享 30 分钟认证缓存尚未实现。词频与词典情感分析不等同于可靠的语义画像。
- 私有 GraphQL 可随平台改变；可见分页结束不代表获得隐藏、删除或受保护内容。

部署者应先执行上述健康检查，再用自己授权的目标进行小范围真实采集，核对账号、覆盖范围和成本。
