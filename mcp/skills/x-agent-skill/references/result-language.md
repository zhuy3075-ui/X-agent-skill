# 面向用户的结果表达约定

这是 agent 的输出规范，不修改 MCP 内部状态、错误和可追踪记录。先核实事实，再组织语言。
不把原因、数量或时间范围补成看似合理的数值。未查到实际覆盖日期时，写“实际覆盖日期尚未核实”。

## 状态翻译

| 内部事实 | 用户表达 | 必须补充 |
| --- | --- | --- |
| 已提交，尚未执行 | “已经安排采集，目前还在等待处理。” | 不能说已经采集；是否能核实后台正在运行 |
| 正在运行 | “正在采集，目前已保存……。” | 只填已核实数量；不知道时不写进度百分比 |
| 成功 | “已完成本次范围的采集，保存……。” | 请求范围、实际范围、平台可见范围限制 |
| 部分完成且有数据 | “已保存……，但本次范围还未采集完整。” | 为什么停止、哪些尚未处理、现有数据仍可用 |
| 部分完成但没有数据 | “这次尚未取得可用内容，采集范围也未确认完成。” | 实际原因，不写“成功采集 0 条” |
| 失败，已有提交数据 | “本次未能完成；已保存的……仍然保留。” | 失败原因、数量和下一步 |
| 失败，无提交数据 | “本次未能取得数据，因为……。” | 可理解的原因和用户能采取的动作 |
| 请求取消但尚未停止 | “已请求停止，当前请求结束后会停止。” | 不提前声称已经停止 |
| 已取消 | “已按要求停止，已保存的……仍然保留。” | 实际成果，未执行时明确没有开始采集 |
| 完成扫描且无匹配数据 | “在指定日期和帖子类型中，没有找到当前账号可见的匹配内容。” | 不推断博主没有发帖；说明筛选范围和可见性限制 |

## 停止原因翻译

| 内部原因 | 通俗说明 |
| --- | --- |
| post_target_reached | “已达到本次设定的帖子数量目标，较早或其余内容尚未继续扫描。” |
| page_budget | “已用完本次设定的采集批次，仍有内容没有继续读取。” |
| runtime_budget | “已达到本次设定的采集时长，剩余内容尚未处理。” |
| comment_post_budget | “本次只读取了设定数量的帖子评论，其余帖子的评论还未读取。” |
| repeated_cursor / unrecognized_page | “平台返回的后续页面重复或无法识别，无法确认是否已经采集完整。” |
| fixture_end | “这次使用的是测试样本，不能把样本结束视为线上数据已经采集完整。” |
| collection_incomplete | “采集没有走完全部步骤。”若没有更具体证据，不猜测为限流或超时 |

达到数量目标不等于覆盖整个日期范围。帖子已完整但评论未完整时，应分别描述，不能把全部工作
笼统判为失败。多个原因并存时优先说明直接影响用户目标的原因，再补充必要限制。

## 错误翻译

| 内部错误 | 用户表达与动作 |
| --- | --- |
| MISSING_CREDENTIAL | “采集端没有读取到登录凭据，本次没有开始访问 X。请通过安全配置入口添加或恢复凭据。” |
| INVALID_TOKEN_FORMAT | “登录凭据格式不正确，请检查是否为空、包含空格或复制不完整。” |
| CREDENTIAL_FILE_ERROR | “登录配置文件无法读取或格式不正确。请检查配置文件和访问权限。” |
| TOKEN_INVALID | “X 已拒绝当前登录凭据，请重新登录获取新凭据并更新配置。已保存的数据不会丢失。” |
| ACCOUNT_LOCKED | “这个账号需要先在浏览器完成安全验证，完成后才能继续采集。” |
| LOGIN_UNCONFIRMED | “暂时无法确认登录是否有效，可能与网络、代理或会话有关。不能据此认定令牌失效。” |
| ACCOUNT_BUSY | “所选账号正在处理其他任务，需要等待当前操作完成。” |
| ACCOUNT_CHANGED | “配置中的登录账号发生了变化，需要先重新确认账号身份。” |
| DUPLICATE_ACCOUNT | “这份凭据对应的账号已经登记，请使用已有的账号配置。” |
| ACCOUNT_DISABLED | “所选账号目前未启用，需要启用后才能采集。” |
| RATE_LIMITED | “当前账号暂时达到请求额度，需要等待额度恢复后继续。”只在有证据时给具体等待时间 |
| SOURCE_FORBIDDEN | “当前账号无法访问目标内容，请检查帖子可见范围或账号权限。” |
| SOURCE_AUTH_REJECTED | “平台拒绝了本次请求，需要重新确认登录或访问权限。”不直接断言令牌过期 |
| SOURCE_NOT_FOUND / TARGET_UNAVAILABLE | “无法访问或识别该博主、帖子或采集接口，请检查目标和接口状态。”不声称一定被删除 |
| DATABASE_ERROR | “数据保存或读取没有完成。”根据已返回的安全原因补充连接、超时或权限问题 |
| INVALID_INPUT | 用中文指出具体缺失字段或不合法约束，例如“结束日期必须晚于开始日期” |
| 未识别错误 | “本次操作未能完成，暂时无法确定具体原因。”说明已确认的成果和可执行的排查动作，不编造原因 |

## 统计与展示约束

- 帖子和评论分开统计；不重复记录数、处理次数、真正新增数不能混用。
- 请求时间范围与实际最早／最晚发布时间分开。对增长，使用观测时间，不冒充发布时间。
- 旧数据参与分析时说明累计样本量与本次采集量；缓存结果附上数据时间，不能声称刚刚更新。
- 报告通常先给成果，再给范围、完整性和内容摘要。只有必要时追加下一步。
- 用户主动要求排障时，可附任务 ID 和错误代码，但主要结论仍用通俗语言说明。
- 用户没有要求后续通知时，等待期限结束不能承诺“完成后自动通知你”。
- 别把十种玩法全部执行一遍；按用户当前目标选择组合。


## 账号等待、档案和续采

- `ACCOUNT_WAIT`：当前账号正在冷却或被占用，任务会在可用后继续；这不是永久失败。
- `ACCOUNT_WAIT_EXHAUSTED`：已等待至本次上限，已有数据保留，说明需要补充有效账号或稍后续采。
- `NO_VALID_ACCOUNT`：没有可用且已验证的账号，明确提示配置／检查凭据，不继续空转。
- `SOURCE_RESPONSE_ERROR`：平台返回的数据不足以确认本页，已保留此前成果；不能写成没有评论。
- `CONTINUATION_EXISTS`：已有续采批次，查询它的实际进度；不要创建重复批次。
- 分页汇总查询已保存评论的不重复总数，不能把最后一批的条数当作整个任务的总成果。
- 档案只表示身份与历史已保存，不等于该博主的帖子或评论已经完整采集。
